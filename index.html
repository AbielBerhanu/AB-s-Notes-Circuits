This course is organized into units covering core topics in introductory circuit analysis. For each unit, a brief overview is provided along with a recommended MIT lecture video and example problems with step-by-step solutions.

Unit 1: Circuit Terminology and Basic Quantities

Key Formulas

  • $I = \frac{dQ}{dt}$
    • - $I$: Current (Amperes, A) is the rate of flow of charge.
    • - $Q$: Charge (Coulombs, C)
  • $P = VI$
    • - $P$: Power (Watts, W)
    • - $V$: Voltage (Volts, V)
    • - $I$: Current (Amperes, A)

Topic Description

This unit introduces the fundamental concepts and terminology used in circuit analysis. Key electrical quantities such as charge, current, voltage, and power are defined, and the lumped circuit abstraction is explained. Students learn what constitutes a node, branch, and loop in a circuit, as well as the notion of a reference ground node. The passive sign convention is discussed to determine whether an element is absorbing or delivering power.

Recommended MIT Lecture: Introduction and Lumped Abstraction

Example 1

A constant current of $I = 2~\text{A}$ flows through a wire. How much electric charge passes through a cross-section of the wire in $t = 3~\text{s}$? Also, if the wire connects a $5~\text{V}$ battery to a resistor, what is the power delivered to the resistor?

Solution:

Step 1: Charge calculation. Current $I$ is the rate of charge flow ($I = Q/t$). Solving for charge $Q$ gives $Q = I \cdot t$. Plugging in values: $Q = 2~\text{A} \times 3~\text{s} = 6~\text{C}$.

Step 2: Power calculation. The power $P$ delivered to an element is $P = V \times I$. The resistor has $5~\text{V}$ across it and carries $2~\text{A}$. Thus $P = 5~\text{V} \times 2~\text{A} = 10~\text{W}$.

Unit 2: Ohm’s Law and Kirchhoff’s Laws

Key Formulas

  • $V = IR$
    • - Ohm's Law.
  • $\sum I_{\text{in}} = \sum I_{\text{out}}$
    • - Kirchhoff’s Current Law (KCL): The sum of currents entering a node equals the sum of currents leaving.
  • $\sum V_{\text{rises}} = \sum V_{\text{drops}}$
    • - Kirchhoff’s Voltage Law (KVL): The sum of voltage rises equals the sum of voltage drops around any closed loop.

Topic Description

This unit covers the fundamental laws governing currents and voltages in circuits. Ohm’s Law ($V = I R$), Kirchhoff’s Current Law (KCL), and Kirchhoff’s Voltage Law (KVL) are introduced. Using these laws allows for the analysis of simple circuits.

Recommended MIT Lecture: Basic Circuit Analysis Method – KVL and KCL

Example 1

A 12 V battery is connected in series with two resistors, $R_1 = 3~\Omega$ and $R_2 = 2~\Omega$. Find the current and the voltage drop across each resistor.

Solution:

Step 1: Total resistance and current. $R_{\text{eq}} = 3~\Omega + 2~\Omega = 5~\Omega$. By Ohm’s law, $I = \frac{12~\text{V}}{5~\Omega} = 2.4~\text{A}$.

Step 2: Voltage drops. $V_1 = I R_1 = 2.4~\text{A} \times 3~\Omega = 7.2~\text{V}$, and $V_2 = I R_2 = 2.4~\text{A} \times 2~\Omega = 4.8~\text{V}$.

Unit 3: Series and Parallel Resistive Circuits

Key Formulas

  • $R_{\text{eq, series}} = R_1 + R_2 + \cdots$
  • $\frac{1}{R_{\text{eq, parallel}}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots$
  • $V_x = V_s \frac{R_x}{R_{\text{total}}}$ (Voltage Divider)

Topic Description

This unit teaches simplification of circuits by identifying series and parallel resistor combinations. Series resistors add directly, while parallel resistors add as reciprocals. The voltage divider and current divider rules are introduced as convenient shortcuts.

Unit 4: Nodal and Mesh Analysis

Topic Description

This unit formalizes two powerful systematic methods for circuit analysis: nodal analysis (using KCL) and mesh analysis (using KVL). Nodal analysis solves for unknown node voltages. Mesh analysis solves for unknown loop currents. Both methods transform a complex circuit problem into a system of linear equations.

Recommended MIT Recitation: Nodal/Mesh Analysis

Unit 5: Linearity and Superposition

Topic Description

The superposition principle states that in any linear circuit with multiple independent sources, we can calculate the effect of each source separately (turning off all other sources), then sum the results. To turn off a voltage source, replace it with a short circuit. To turn off a current source, replace it with an open circuit.

Recommended MIT Lecture: Superposition, Thévenin and Norton (Part 1)

Unit 6: Thévenin and Norton Theorems

Key Formulas

  • $V_{th} = V_{oc}$ (Thévenin Voltage is open-circuit voltage)
  • $I_{no} = I_{sc}$ (Norton Current is short-circuit current)
  • $R_{th} = R_{no} = V_{th} / I_{no}$ (Equivalent Resistance)

Topic Description

Thévenin’s Theorem states that any linear two-terminal network can be replaced by an equivalent circuit of a single voltage source $V_{th}$ in series with a resistor $R_{th}$. Norton’s Theorem provides an equivalent circuit of a single current source $I_{no}$ in parallel with a resistor $R_{no}$. These theorems are powerful for simplifying circuit analysis.

Recommended MIT Lecture: Superposition, Thévenin and Norton (Part 2)

Unit 7: First-Order (RC & RL) Circuits

Key Formulas

  • $\tau = RC$ (Time constant for RC circuits)
  • $v_C(t) = V_f + (V_i - V_f)e^{-t/\tau}$ (Capacitor voltage response)

Topic Description

This unit introduces circuits containing energy storage elements (capacitors and inductors), leading to time-varying behavior described by differential equations. We focus on first-order RC (resistor-capacitor) and RL (resistor-inductor) circuits. The concept of the time constant ($\tau$) is introduced, which characterizes the rate at which these circuits charge or discharge.

Recommended MIT Lecture: Capacitors and First-Order Systems

Unit 8: Sinusoidal Steady-State Analysis

Topic Description

This unit introduces methods for analyzing circuits driven by sinusoidal (AC) sources. We explore concepts like phase and frequency, and the use of phasors to represent sinusoidal voltages and currents, which simplifies analysis by converting differential equations into algebraic equations in the frequency domain.

Recommended MIT Lecture: Sinusoidal Steady State

Unit 9: AC Power & Impedance

Topic Description

We extend AC analysis by introducing impedance ($Z$), the complex generalization of resistance that applies to capacitors and inductors. We cover concepts of AC power, including average power, reactive power, and the power factor, which are crucial for understanding energy efficiency in AC systems.

Recommended MIT Lecture: The Impedance Model

Unit 10: Operational Amplifiers (Abstraction)

Topic Description

This unit introduces the operational amplifier (op-amp) as an essential building block in analog electronics. We focus on the ideal op-amp model, characterized by infinite input impedance, zero output impedance, and infinite open-loop gain. This abstraction simplifies the analysis of circuits containing op-amps.

Recommended MIT Lecture: The Operational Amplifier Abstraction

Unit 11: Op-Amp Circuits

Topic Description

Building on the ideal op-amp model, this unit covers fundamental op-amp circuit configurations, including the inverting amplifier, non-inverting amplifier, summer, and difference amplifier. We analyze how feedback networks determine the closed-loop gain and function of these circuits.

Recommended MIT Lecture: Operational Amplifier Circuits

Unit 12: Frequency Response & Bode Plots

Topic Description

This unit explores how the behavior of circuits changes with the frequency of the input signal. We introduce the concept of the transfer function and use Bode plots to visualize the frequency response (magnitude and phase) of circuits, which is essential for designing filters and understanding system stability.

Recommended MIT Lecture: Filters
